# 定石学習（Phase 8）

`learn-book` は Buro の定石学習（Buro 1999，設計ドキュメント §4.3.7）を
再現する．**自己対局 + Negamax バックプロパゲーション + drawishness** で
定石を学習する．明示的なリトルエンディアン `OPB1` 定石を書き出し
（[`BOOK_FORMAT.md`](../../crates/logistello-book/BOOK_FORMAT.md)を参照），
`--seed` を固定すれば決定的である．

## `learn-book` — 定石を学習する

```bash
cargo run --release -p logistello-cli -- learn-book \
    --num-games 1000 --depth 24 --drawishness 0.3 --seed 1 \
    --output results/book.opb1
```

| フラグ | 意味 | 既定値 |
|---|---|---|
| `--num-games` | 自己対局数（設計ドキュメント §5.1: 10000） | `1000` |
| `--depth` | 1 手あたり自己対局探索深さ（§5.1: 24; §6 `--book-depth-values {12,18,24,30}`） | `24` |
| `--drawishness` | drawishness ブレンド `λ ∈ [0,0.5]`（§5.1: 0.3; §6 範囲 `0.0..0.5`）．範囲にクランプ | `0.3` |
| `--seed` | （決定的）探索方策の RNG シード | `1` |
| `--max-book-plies` | 定石対象の親プライ上限（序盤のみの定石境界） | `20` |
| `--book-endgame-empties` | これ未満の空きマスでは定石化しない下限 | `30` |
| `--eval-weights` | 任意の `LGW1`: `BasicEval` ではなく `PatternEval` で自己対局 | — |
| `--output` | 出力 `OPB1` 定石パス（必須） | — |

## 学習済み定石で対局する

```bash
cargo run --release -p logistello-cli -- play \
    --black engine --white random --depth 8 --seed 42 \
    --book results/book.opb1
```

`--book` 指定時，`engine` プレイヤはまず定石を参照する．現局面が定石化
されていて（かつ定石手が合法なら）探索せず定石手を指す．定石域を抜けると
通常探索にフォールバックする（他の全フラグと併用可）．

> **正直な注記:** §4.3.7 の機構は，Buro 1999 のとおり自己対局 + リーフ値の
> Negamax バックプロパゲーション + drawishness `λ` ブレンドを忠実に
> 実装している．1 点の簡略化を明記する．定石局面を発見する自己対局は，
> ゲーム全体を単一探索深さ `--depth D` で行う（反復／可変深さスケジュール
> ではない）ため，定石は深さ `D` 自己対局と同程度の弁別力しか持たない．

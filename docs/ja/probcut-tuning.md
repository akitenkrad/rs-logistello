# ProbCut と Multi-ProbCut のチューニング（Phase 5-6）

> **ProbCut とは（正直な説明）:** ProbCut / Multi-ProbCut は**不健全な
> 前向き枝刈り**である．厳密ではなく*統計的*である．深さ `d` の浅い
> プローブ探索が，OLS モデル `v_h = a·v_d + b`（残差 σ）を介して深さ `h`
> の値を予測し，σ あたりの信頼係数 `T` が枝刈りの可否を決める．したがって
> 枝刈りは誤りうる — Buro の論文どおり，厳密性と速度をトレードオフする．
> 当てはまりの良さ（R²）は評価器に依存する．自明な `BasicEval` では
> R² ≈ 0.83 だが，学習済みパターン評価では設計ドキュメント §4.5 B7 の目標
> は R² > 0.96 である（B7）．

## `probcut-fit` — `(a, b, σ)` 係数の当てはめ（Phase 5/6）

`probcut-fit` はサンプル各局面で，必要な各深さの真値
`v_x = NegaScout(x)` を本番 TT 規律下（ProbCut/MPC OFF）で測定し，
ディスク局面（`< 36` か `≥ 36`）で層別し，グループごとに OLS
`v_h = a·v_d + b` を当てはめる．

```bash
# 単一 ProbCut: 1 つの (d, h) ペア（設計ドキュメント §4.5 B7 単一 ProbCut = 4:8）
cargo run --release -p logistello-cli -- probcut-fit \
    --single-pair 4:8 --samples 5000 --seed 42 \
    --output results/probcut_params.json

# Multi-ProbCut カスケード: (disc-phase, h, d) セルごとに独立した OLS
cargo run --release -p logistello-cli -- probcut-fit \
    --mpc-cascade 3:1,4:2,5:1,6:2,7:3,8:4,9:3:5,10:4:6,11:3:5,12:4,13:5 \
    --samples 5000 --seed 42 --output results/mpc_params.json
```

| フラグ | 意味 | 既定値 |
|---|---|---|
| `--single-pair` | 浅:深ペア `d:h`（`--mpc-cascade` 不在時に使用） | `4:8` |
| `--mpc-cascade` | カスケード仕様 `h:d1[:d2],...`; `(disc-phase, h, d)` 当てはめを実行 | — |
| `--source` | `selfplay`（シード付き，外部データ不要）または `wthor` | `selfplay` |
| `--wthor-dir` | `.wtb` ファイルのディレクトリ（`--source wthor` で必須） | — |
| `--samples` | 当てはめるサンプル局面数 | `5000` |
| `--seed` | 自己対局 RNG シード（決定的） | `42` |
| `--eval-weights` | 任意の `LGW1`: `BasicEval` ではなく `PatternEval` で当てはめ（B7 R² > 0.96） | — |
| `--probcut-t` | 単一 `ProbCutConfig` に書き込む σ あたり信頼係数 `T`（`--mpc-cascade` では無視，正規の 2 相 1.0 / 1.4 を保持） | `1.5` |
| `--output` | 出力 JSON（`ProbCutConfig` または `MultiProbCutConfig`） | 必須 |

## `play` / `bench-search` で当てはめ済みパラメータを使う

`--probcut` / `--mpc` 実行は対応する当てはめ済みパラメータ JSON があって
初めて意味を持つ（組み込み既定には当てはめ済み係数がなく，ProbCut は
素通りする）．

```bash
# 単一 ProbCut
cargo run --release -p logistello-cli -- play \
    --black engine --white random --depth 8 \
    --probcut --probcut-params results/probcut_params.json

# Multi-ProbCut（カスケード高 3..=13 で単一 ProbCut を上書き）
cargo run --release -p logistello-cli -- bench-search \
    --depth 10 --mpc --mpc-params results/mpc_params.json

# 厳密探索に対する高速化を観測
cargo run --release -p logistello-cli -- bench-search --depth 10 --speedup \
    --probcut-params results/probcut_params.json \
    --mpc-params results/mpc_params.json
```

`play` / `bench-search` のフラグ表全体は[はじめに](getting-started.md)を参照．

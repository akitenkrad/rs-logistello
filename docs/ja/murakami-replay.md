# 村上 1997 戦リプレイ — ゴールド検証セット

1997 年の村上健 対 Logistello 戦（歴史的な 6-0 スイープ）は，本再現の
**ゴールド検証セット**（設計ドキュメント §4.5 B5，§5）である．生の FFO
WThor データベースは第三者由来で gitignore（`data/`）．*派生*の 6 局 JSON
は小さくコミット済み（`tests/data/murakami_1997.json`）．

## 1. 生の WThor DB を取得する

`scripts/fetch_wthor.sh` は生の WThor 1997 ベースと共有のプレイヤ／大会名
DB を gitignore された `data/wthor/` へ取得する（冪等．`FORCE=1` で再
ダウンロード）．

```bash
bash scripts/fetch_wthor.sh
```

## 2. 6 局のゴールド棋譜を抽出する

`murakami-extract` は `--wthor-dir` 内の全 `.wtb` を解析し，兄弟 `.jou`
でプレイヤ id を解決し，一方が "Logistello" もう一方が "Murakami"
（大文字小文字無視）の局を保持して，小さなコミット済み JSON ゴールド
セットを書き出す．発見した局数と名前を正直に報告する（1997 年は 6 を
期待）．

```bash
cargo run --release -p logistello-cli -- murakami-extract \
    --wthor-dir data/wthor --output tests/data/murakami_1997.json
```

| フラグ | 意味 | 既定値 |
|---|---|---|
| `--wthor-dir` | FFO `.wtb` + `WTHOR.JOU` を含むディレクトリ | `data/wthor` |
| `--output` | 出力 JSON（コミット済みゴールドセット） | `tests/data/murakami_1997.json` |

## 3. リプレイして着手一致率を報告する

`match-replay` は記録した対局をリプレイし，本エンジンの着手一致率
（全体 + 「メイン局面」プライ窓，設計ドキュメント §4.3.8
`move_match_rate_murakami`，§5 メイン局面で ≥80%）を報告する．

```bash
# 中規模重み（学習は evaluation-training.md を参照）:
cargo run --release -p logistello-cli -- match-replay \
    --games tests/data/murakami_1997.json \
    --eval-weights results/eval_weights/wthor_medium.lgw1 \
    --depth 8 --output results/murakami_replay.csv
```

| フラグ | 意味 | 既定値 |
|---|---|---|
| `--games` | コミット済みゴールドセット JSON（`murakami-extract` 出力） | `tests/data/murakami_1997.json` |
| `--eval-weights` | `PatternEval` の `LGW1` 重み．省略時は `BasicEval` | — |
| `--book` | 任意の学習済み定石（`OPB1`） | — |
| `--depth` | 選択的中盤の反復深化深さ（プライ） | `8` |
| `--endgame-empties` | 厳密終盤切替閾値（空きマス; B8） | `20` |
| `--mpc-params` | 任意の Multi-ProbCut パラメータ JSON（`probcut-fit` 出力） | — |
| `--main-lo` / `--main-hi` | 「メイン局面」プライ窓（両端含む，設計ドキュメント §5） | `10` / `50` |
| `--output` | 出力 CSV（`results/<ts>/` にもコピー） | `results/murakami_replay.csv` |

`match-replay` は CSV をタイムスタンプ付き `results/<YYYYMMDD_HHMMSS>/`
ディレクトリにもミラーし，`results/latest` シンボリックリンクを張る
（設計ドキュメント §4.2）．

> **注意（正直な注記）:** コミット済みの簡易実行は *中規模* の WThor 学習
> 重み（数百局コーパス，数分の学習）を使い，本番 Logistello-2 コーパス
> ではない．中規模重みの着手一致は §5 ≥80% ／歴史的目標より弱い．その
> 水準は本番規模学習向けである．本番コマンドは
> [フルスケール再現](full-scale-reproduction.md)を参照．
